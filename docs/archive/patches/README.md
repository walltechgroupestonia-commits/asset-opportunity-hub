# Archive: patches

This directory holds archived patch notes, small fixes, and one-off patch files for the project.

Guidelines
- Place patch files or short notes here when you need to preserve a local fix or a small change that shouldn't be part of the main docs navigation.
- Use a clear filename and date prefix, e.g. `2026-08-07-fix-build-warning.patch` or `2026-08-07-README-typo.md`.
- Do not rewrite published git history. Avoid rebasing, force-pushing, amending, or squashing commits that are already pushed — this repository is connected to Lovable and rewriting history can cause loss of project history.

If you want an empty directory placeholder instead, add a `.gitkeep` file here instead of a README.
